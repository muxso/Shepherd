# 云效原生页面验收摘要

本文保留原生投影与页面能力的历史验收范围。部署地址、项目规模、业务编号、人员数据和备份位置属于私有运维记录，不随开源代码发布。当前配置方式见 [云效接入文档](YUNXIAO.zh-CN.md)。

## 数据完整性

- 外部需求导入原生需求时保留来源、正文、状态和优先级；正文变化生成不可变版本。
- 功能用例保留用例库、目录、创建人、来源时间、前置条件、步骤和预期；源空值如实保留。
- 完整源快照及原生投影在事务中发布，失败保留上次成功数据；已有手工数据、关联和执行结果不被覆盖。
- 部署前核对历史迁移校验和；构建缓存必须随迁移目录变化失效。

## 页面与统计

- 统计页面可滚动到全部数据标签；大目录使用线性索引和子树计数缓存。
- 富文本正文解析 HTML 与 JSON 封装，统一经过 DOMPurify 过滤；普通 Markdown 和 JSON 示例保持原格式。
- 已交付但没有子任务的需求可按一个人工工作项计数；存在任务时沿用实际任务口径，防止重复计算。
- 交付日期采用真实验收或状态变更时间，不以导入时间补造。
- 需求协作统计按来源角色聚合；关注人、创建人、未知身份和 Agent 身份不自动归为贡献人员。
- 没有任务的已交付需求可在登记参与人之间均分交付量；不将均分结果解释为工时或投入比例。
- 来源需求详情保留可分享的项目范围链接。
- 关联代码只采用明确关联到需求的提交，兼容来源需求 ID 和编号；排除合并提交，未知行数如实显示，不按标题猜测关联。

## 回归范围

- 工作区格式、Clippy、前端类型检查和生产构建。
- 隔离 PostgreSQL 测试：不可变版本、来源身份、事务回滚、任务与需求去重、角色合并、跨项目隔离、删除过滤、未知作者和缺失行数。
- 浏览器测试：完整分页、目录导航、正文预览、详情刷新、交付日历、人员搜索和关联代码展示。
- 对已运行环境的回归仅做只读检查；凭据、截图、数据库备份和实际运行结果应保存在私有位置。
