# 项目业务数据问答

网页聊天和企业微信共用 `/rag/ask/stream`。业务统计直接读取当前项目记录，由服务端计算数字；文档问题检索当前账号有权查看的知识资料。

## 查询范围

覆盖需求、缺陷、功能用例、测试计划与执行、用例评审、接口定义与用例、接口场景与执行、性能报告、研发任务、交付记录、设计方案、验收追溯、项目服务、功能场景与执行、接口梳理、需求影响面评审、文件元数据、项目成员、Skills 元数据、项目模板和当前项目。文件正文、环境凭据、接口鉴权配置和可执行 Skill 指令不属于此业务查询目录。

可以提问：

- 项目概览：需求、缺陷、功能用例各有多少？
- 功能用例按服务统计图。
- 最近 30 天失败的接口执行报告有哪些？
- 查询名称包含“支付”的需求。
- 云效最近 7 天新增缺陷统计图。
- 每个组本周的代码热力图。

项目成员身份和各资源读取权限仍然生效。模型只选择登记的查询能力与经过校验的条件，不能提交 SQL、任意 URL 或执行操作。查询有超时限制，合计计算全部匹配记录，明细最多显示 12 条，分布最多显示 100 类。日期按上海时区计算；缺少对应时间的记录单独说明。外部数据受采集覆盖范围限制。

Git 活动不能直接评价工时或绩效。每日作者摘要不能证明依赖由谁修改，更不能证明生产故障责任；需要实际 diff，以及部署和运行证据。失败和未授权查询不能解释为零条记录。

## 企业微信授权

在“系统参数 → RAG”配置机器人专用账号和渠道。开启渠道后，为具体群聊或私聊用户关联项目。群绑定使用独立开关，默认关闭；开启后由管理员生成限定项目、有效期和单次使用的绑定码，不支持通配会话授权。

连接器设置 `WECOM_REMOTE_POLICY=1` 后强制使用后台授权，切换前需明确迁移原有绑定。心跳超过 90 秒视为过期；后台分别展示授权启用状态和实际连接状态。待授权列表只保留会话身份，不保存消息正文。详见[连接器说明](../plugins/wecom-bot/README.md)。

## 新人入职知识

聊天页和 RAG 设置页的“入职知识”可维护项目指南和 FAQ。填写核实后的正文、可用的来源链接和可见组。可见组留空时，仅维护者与管理员可见；如需机器人回答，应关联机器人专用账号角色有权访问的可见组。

发布时更新检索内容并保存编号版本，旧版本并发修改会被拒绝。入职和公司制度问题限定检索已维护且有权访问的入职资料。系统不预填公司制度，资料缺失时应说明证据不足。引用使用已记录的来源链接或受权限保护的文档页面，并在已知时显示事件或发布时间。
