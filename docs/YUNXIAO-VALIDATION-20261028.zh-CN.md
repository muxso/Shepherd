# 云效接入验收摘要

本文保留初始集成的历史验收范围，不包含部署环境或真实业务数据。原生投影能力见 [原生页面验收摘要](YUNXIAO-NATIVE-VALIDATION-20261028.zh-CN.md)，当前配置方式见 [云效接入文档](YUNXIAO.zh-CN.md)。

## 集成检查

- 格式、Clippy、前端类型检查、生产构建及隔离数据库测试。
- 完整快照发布、数量校验、分页去重、重复同步、状态历史去重、失败保留旧数据和并发运行拒绝。
- Python 采集分批限制，以及来源优先级、负责人和时间字段保真。
- 新迁移与历史校验和一致性；隔离数据库启动、健康检查、路由注册和未登录访问拒绝。
- 通过反向代理验证看板、需求、缺陷、迭代、提交、状态历史和运行记录接口。
- 核对分组、搜索和延期过滤，以及完整同步与同一快照重放的幂等性。

## 验证边界

来源内容和滚动时间窗口都会影响记录数量，不将固定业务数量作为产品约束。外部导入不生成模拟 AI 交付、任务验收或执行结果。

浏览器验收与接口检查分别记录；没有完成截图检查时，不将构建或 HTTP 检查表述为视觉验收。

实际来源标识、环境地址、凭据、运行日志、业务快照和备份位置仅保存在私有运维系统中。开源文档使用通用示例，自动化测试使用合成数据。
