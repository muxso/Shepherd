# Yunxiao pilot validation, October 28, 2026

This is an archived record of the initial integration, superseded by the [isolated plugin architecture](YUNXIAO.md). It does not describe the current storage boundary or deployment procedure.

The pilot verified atomic snapshots, count validation, idempotent replay, status history, permissions, pagination deduplication, and read-only collection. It originally stored external facts in the Shepherd database. A later implementation also projected native assets; that behavior has been removed.

See the [detailed Chinese pilot record](YUNXIAO-VALIDATION-20261028.zh-CN.md) and [native projection archive](YUNXIAO-NATIVE-VALIDATION-20261028.md).
