# 企业微信项目聊天接入

使用企业微信智能机器人「API → 长连接」模式，无需公网回调地址。普通群机器人 Webhook 只能发消息，不能接收群内 @。

接入后，授权群的问题通过 Shepherd `/rag/ask/stream` 查询项目资料并流式回复。发送「最近 7 天代码提交统计图」等明确统计请求，可以收到 PNG 图表。支持今天或最近 1～365 天；暂不支持读取用户发送的图片或任意图片生成。群聊历史按群和发送者隔离保存在接入服务 PVC 中，与网页聊天历史独立。

配置步骤及 Kubernetes 示例见 [English setup](README.md)。配置时需要：

1. 企业微信智能机器人的 Bot ID 和 Secret。
2. 一个只读 Shepherd 用户，加入目标项目；为其创建限定权限的个人 API Key，避免使用管理员凭据。
3. 为机器人角色配置知识库可见组，只分享预期项目资料，并让后续同步保留同样的可见组。不要默认共享个人上传资料。
4. 在集群 Secret 中设置机器人凭据、后端地址、限定权限的 Key 和随机一次性绑定码；在 ConfigMap 中指定项目。真实配置不要提交到 Git。
5. 构建镜像，替换 `deploy/kubernetes.yaml` 中的项目和镜像占位符，部署到后端所在命名空间。保持一个副本，采用 `Recreate` 更新策略。
6. 将机器人加入目标群，在群里 @ 它并发送 `绑定 <一次性绑定码>`。收到成功回复后，再 @ 提问。绑定码只能授权一个群；也可在私有配置 `allowedChatIds` 中明确允许群 ID。

授权群的所有成员均可查询机器人共享的项目资料，回复对全群可见。服务不会主动发送欢迎或定时消息。`/readyz` 表示企业微信已认证，`/healthz` 表示进程存活；不需要公开 Service 或 Ingress。

PVC 保存群绑定、消息去重和聊天历史；每名发送者保留最多 100 条消息，在后续写入时清理超过 30 天的历史。请备份私有卷。撤销授权时先停服务，再移除配置与数据库中的群绑定；也可以更换状态卷并轮换绑定码。撤销 Shepherd API Key 可停用全部资料访问。

Git 工作梳理直接读取目标项目已采集的团队活动，按指定人员和上海日期过滤，不由模型生成日期或提交依据。自然周为周一至周日；例如 2026-11-08（周日）的本周为 11/02～11/08，上周为 10/26～11/01。支持最近 N 天及 `YYYY-MM-DD 至 YYYY-MM-DD`；受已采集覆盖和最近 365 天范围限制。回复明确列出范围、同步时间和最多 15 条提交链接。

日报核对可使用用户发来的文字条目，在所选范围的 Git 提交与关联云效需求中定位候选证据。标题相似仅作候选，不能证明同一业务、生产发布、测试次数或工作真实性；未找到候选也不代表没有工作。当前不自动读取未关联提交的代码差异、发布流水线或未提供的群历史。
